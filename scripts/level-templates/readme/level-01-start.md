# EWB Banking Portal — Level 1: Welcome

You're on the **Level 1 Start** branch. This is your starting point.

## What's Here

- `portal/src/types/` — Empty type definitions for you to fill in
- `portal/` — A bare Vite + React + TypeScript project

## What You'll Build

In Level 1, you'll learn React fundamentals, TypeScript for React, and compliance thinking. Your tasks:

1. Define banking domain types in `src/types/common.ts`
2. Create type exports in `src/types/index.ts`
3. Write your first utility functions

## Getting Started

```bash
cd portal
npm install
npm run dev
```

## When You're Done

Compare your work with the reference implementation:

```bash
git diff level-01-start level-01-complete
```

Then move to Level 2:

```bash
git checkout level-02-start
npm install
```
